## 本次更新

- **进入会话不再向上翻历史**：打开会话会稳定停在最新一条消息；只有你主动上滑到顶部时才会加载更早的历史，不再出现首屏“抽搐式”向上加载到最顶的问题。
- **修复超级岛闪烁**：灵动岛总览改为按实际渲染内容更新，任务运行中的瞬时状态变化不再重发通知；结束后延迟复核才收起，澎湃 OS 息屏下不再每隔几秒消失又弹出、并触发“收到通知”动画。
- **会话底部常驻运行指示**：正在运行的会话底部始终显示「运行中 · 用时」，时间每秒刷新；运行中的轮次不再显示不会变化的静态“用时”，避免误以为会话已结束。
- **工具调用按电脑端方式分组**：连续同类工具调用折叠为「使用了 N 个 Shell」等一行；点击进入半屏窗口后每条记录一行（含“思考”），点开某一条才显示具体命令、输出或思考内容。
- **修正“后台运行中”判断**：此前只要应用短暂退到后台（包括打开系统图片/文件选择器），本轮剩余时间都会被标成“后台运行中”。现在只有“主线程已空闲、仍在等待派生的后台/子任务”才显示“后台运行中”，正在运行的会话显示“运行中”。

## 已知限制

- 澎湃 OS 超级岛/息屏表现依赖厂商行为，建议在目标真机上息屏连续运行确认不再闪烁。
- “后台运行中”语义已调整：只表示“主线程空闲、在等派生任务”，不再表示“应用离开期间仍在运行”。
- 工具分组由「上下文合并 / 达到阈值才折叠」改为「按类别始终折叠」；如需“混合工具合并为一行”的样式可后续调整。
- 荣耀灵动胶囊、OPPO ColorOS 15 流体云等厂商通道仍未接入，当前以 Android 16 标准 Live Updates 为唯一通道。
- 若从历史 debug 签名版本升级，需要先卸载（历史包无法被稳定证书覆盖）；参见 `docs/ANDROID_SIGNING.md`。
