## 本次更新

- **自动刷新更快**：对账改为自适应（有任务 10 秒 / 空闲 30 秒），回到前台阈值降到 5 秒；设置新增「自动刷新：标准 / 更快」，默认「更快」。实时更新仍以事件流为主，不会形成请求风暴。
- **通知更克制**：通知中心不再堆积每个运行中会话的通知；前台服务直接复用「灵动岛」总览。只有任务完成/失败和「需要输入」会发普通通知，且可被通知中心一键清空；全部结束后不再保留总览通知。
- **工具调用改半屏查看**：「已收集上下文 / 已处理 N 个操作 / 本轮改动 N 个文件」以及终端调用，点击后弹出半屏窗口滚动查看，替代原来的行内展开。
- **终端与改动着色**：diff 的 `+` / `−` / `@@` 与 shell 的 `$` 命令行分别着色。
- **界面深浅色统一**：修正深色基主题导致的窗口底色，根页面统一 MIUIX 画布（浅色 `#F7F7F7` / 深色纯黑），首页与设置页不再一个灰一个黑。
- **设置精简**：流体云只显示当前生效模式（如「系统实时更新 · 已就绪」）；删除无用的「已保存的项目权限」。
- **管理模型更直接**：按首页选中的服务器加载模型目录，连接后即可打开「管理模型」，不必先打开一个会话。
- **预测式返回跟随手指**：从左侧或右侧边缘返回时，页面朝手指出来的方向移动，并预览上一级。
- **键盘自动回底**：会话页弹出键盘时自动滚动到底部，最后几条不再被键盘挡住。
- **修复「等待输入」闪动**：服务器仍在执行时保留等待态，不再出现「运行中 → 等待输入 → 立刻又运行中」的抖动。
- **后台运行中提示**：应用在后台期间继续运行的任务，回到前台后会在首页、灵动岛和会话内显示「后台运行中」，直到该轮结束。
