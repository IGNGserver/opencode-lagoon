## 本次更新

- 前端按 Qoder 的结构重新设计，全部使用 MIUIX 组件（#62–#65）：
  - 去掉底部 Dock 和「活动」页。「会话」是唯一首页：左上「全部会话 ⌄」选择项目范围，右上圆形 ⋯ 收纳分组方式、搜索、已归档和设置；设置改为整页打开。
  - 标题下方是服务器胶囊：当前服务器带连接状态点，点按切换、长按编辑、＋ 添加。右下角悬浮按钮新建会话，未连接时会提示原因。
  - 会话列表可按日期（今天 / 昨天 / 近 7 天 / 近 30 天 / 更早）、项目或状态（需要处理 / 运行中 / 未读结果 / 其他）分组，每组可收起。每行只显示标题和一个状态图标：运行中转圈、等待授权或回答显示警示图标、未读结果显示圆点。
  - 长按会话可置顶、重命名、归档、删除。置顶只保存在本机。
  - 会话页改为圆形返回按钮、标题加「服务器 · 项目」副标题；右上 ⋯ 分「查看」（子任务、改动、文件）和「操作」两组。侧滑返回时能看到真实的上一页。
  - 输入框平时是一条胶囊（＋、Agent、输入、发送），输入时展开成卡片，可切换 Agent 和模型；＋ 可添加图片、手机文件和服务器文件。每轮回复末尾可一键复制。
  - 新增「已归档」页，列出服务器上已归档的会话。只有服务器在 `/openapi.json` 里声明支持归档时，才显示「归档」操作。
  - 修正了所有「⌄」下拉箭头原先显示成「展开全屏」图标的问题。
- 适配 OpenCode 2.x 服务端协议（#61）：
  - 实时事件、时间线投影和发送方式与官方 2.x 客户端一致，消息实时更新，不再整页刷新。
  - 系统提示、模型切换、上下文压缩等记录以一行提示显示，不再被当成 AI 回复。
  - 待授权与提问按会话所在位置读取，处理后不会再被误清除；重命名、删除和手机附件在 2.x 上恢复可用。
  - **不再支持 OpenCode 1.x 服务器。**

## 已知限制

- 新界面未在 HyperOS 真机上验收，返回手势、弹层位置和真机观感待确认。
- 当前已发布的 OpenCode 2.x 协议没有归档写入接口，所以在大多数服务器上「归档」不会出现，只能查看在其他客户端归档的会话。
- 置顶不跨设备同步。宽屏设备与手机使用同一布局，不再显示侧边导航栏。
- 运行 OpenCode 1.x 的服务器无法连接，需要先升级到 2.x。
