## 本次更新

- 会话首页与项目范围交互升级（#59）：
  - 顶栏全面适配 HyperOS 大标题风格，上滑收缩为居中小标题，支持原生下拉刷新。
  - 左上角新增带描边的设备胶囊与连接状态点；大标题“全部会话 ⌄”集成范围选择器，支持平铺查看或按项目过滤，移除旧版冗余的单行切换栏。
  - 项目面板支持直接浏览服务端目录（V2 `/api/location`、V1 `/path`），带面包屑导航与一键添加。
  - 新建会话改为空白页“首发即建”模式，未发送不占位，输入框支持快速切换目标项目并继承草稿附件。
- 会话内页按 MIUIX 规范重构并支持手机附件（#56）：
  - 精简冗余操作与密集按钮，整段回复支持长按跨段落选择，辅助操作统一收拢至右上角菜单。
  - 输入区域改为圆角一体化输入框，支持直接发送手机图片（自动按 EXIF 纠偏并压缩）及文本文件（Data URI 内联传输）。
  - 模型选择遵循官方半年内活跃款展示规则，新增客户端独立模型开关与最近使用缓存。
- 会话稳定性与自动对账修复（#55, #58）：
  - 修复聊天 LazyColumn 重复 Part ID 导致的 Compose 崩溃问题，底层补充稳定 ID 映射与容错。
  - 运行态子阶段（思考、工具执行、子任务）对外文案统一规范为“运行中”，增加本地防闪退崩溃日志记录。
  - “已完成 / 失败”结果改为本机见证的未读账本机制，打开会话即消除；补全 V2 根会话查询与前后台静默刷新机制。
- 系统级超级岛 / 实时更新精简（#57）：
  - 移除应用内自绘浮岛悬浮窗，全面接入 Android 16 / HyperOS 系统级实时更新（Live Updates）与超级岛标准通知模板。

- 应用被系统杀死（Force Stop）后将无法在后台接收远程任务更新通知；前台或后台挂起时由前台服务正常保障。
