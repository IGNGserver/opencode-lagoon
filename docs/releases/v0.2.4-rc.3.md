## 本次更新

- 修复多客户端同时在线时工具调用权限在手机端被误判为“等待授权”且无法清除的问题。
- 容错处理已在电脑端或其他端被自动批准（autoaccept）并注销的权限请求，手机端收到或回复已消费的权限（HTTP 404）时宽容放行并自动从待审批列表中移除，不再阻塞后续任务状态。
- 通知栏快捷操作对已失效/已完成的授权请求做平滑收敛，避免异常报错。
- 对齐事件流中 `permission.replied` 与 `form.replied` 的 ID 匹配逻辑。
