## 本次更新

- Android 16 实时更新总览新增标准进度状态轨道，以蓝色表示运行中、琥珀色表示待处理、绿色表示已完成、红色表示失败。
- 状态轨道按各类任务数量展示当前状态组成，不伪造任务完成百分比或预计剩余时间；状态栏胶囊继续使用简短文案。
- Android 15 及以下系统继续使用原有文字通知回退方案，任务汇总仍由服务器状态统一驱动并保持单一实时更新通知所有者。
