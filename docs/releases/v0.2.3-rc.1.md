## 本次更新

- 项目支持从本机移除：项目选择列表新增「⋯ → 从本机移除」，只删除此设备上的项目记录并同步清理本机选择，不会删除服务器上的任何目录或数据。
- 浏览服务器目录新增「显示隐藏目录」开关：默认隐藏点开头的目录与文件，列表与搜索结果统一过滤，只有隐藏项时给出提示，可随时开启查看。
- 运行中会话不再整体转圈：只有真正仍在执行的工具调用与思考显示运行动画，已完成的批次保持完成态，不再误导成“仍在运行”。
- 修复上翻加载更早历史后视口跳到已加载范围顶部的问题：新历史插入后保持原滚动位置，数据确实加载了更多，可继续自行上滑浏览。
- 后台任务识别对齐官方派生算法：模型自发的后台 shell 与子代理在运行期间不再被误报为已完成，正确显示「后台运行中」直到真正结束。
- 移除各厂商灵动岛适配（vivo 原子岛、OPPO 流体云、荣耀灵动胶囊、小米焦点通知模板），统一走 Android 16 系统实时更新（Live Updates），由厂商系统自行映射到自家岛 / 胶囊；设置页相应精简。
