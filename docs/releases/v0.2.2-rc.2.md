## 本次更新

- **历史消息可以一直往上翻**：修复会话上滑只能触发 0~1 次、之后无法继续加载更老消息的问题；加载更早分页时按当前可见消息锚定，插入后位置不再跳动。
- **运行中的轮次展开、完成的轮次折叠**：任务进行中，这一轮按「过程回复 + 第 N 轮调用的一组 + 过程回复 + 正在进行的调用」原样展示，调用与思考内容直接可见；完成后整轮折叠为「共处理 N 个操作 + 最终回复」，上一轮仍整组折叠。
- **项目列表改存本机、手动添加**：项目列表不再自动同步服务器，改由每台设备本地维护；在「全部会话 ⌄ → 添加服务器目录」里浏览服务器目录并点选添加。添加时由服务器解析该目录对应的项目（canonical 路径），同一文件夹不会在服务端生成两个项目。升级后本地项目列表会重置为空，服务器上的项目、会话与文件不受影响。
- **Agent 选择更简洁**：会话内的 Agent 下拉只保留 `build` 和 `plan`，不再显示介绍文字，也不再是半屏窗口。
- **模型与思考强度分开选择**：模型选择和思考强度（服务端提供的 variants）各是一个小型下拉，不再是半屏窗口；移除「管理模型」入口。
- **远程目录页面重做**：服务器目录页与会话文件页改用面包屑、目录优先排序、搜索，并显示明确的加载/空/错误状态。
