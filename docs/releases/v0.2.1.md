## 本次更新

- **重做会话聊天体验**：聊天页采用接近 Qoder 的深色聊天布局，加入右对齐用户气泡、胶囊输入栏、运行状态指示和更清晰的上下文层级；首页、设置和服务器管理页面保持原有主题。
- **按用户轮次聚合操作**：每个用户轮次最多显示一个稳定的「已处理 N 个操作」分组，过程输出按时间线保留，思考与工具正文在展开后查看，避免主聊天被工具细节淹没。
- **补全操作详情**：支持查看命令与输出、读取路径与内容、写入内容、编辑前后文本、复制代码、附件以及子会话入口。
- **改进交互与滚动**：操作列表使用半屏覆盖层，支持遮罩关闭和分级返回；返回详情后恢复列表位置，键盘弹出时保持最新消息可见，历史分页加载时保留滚动锚点。
- **增强实时投影稳定性**：过程文本与最终回答正确分类，回答片段合并为稳定行，重复工具调用 ID 不再导致列表 key 冲突，附件 URL 去重并保留文件打开入口。
