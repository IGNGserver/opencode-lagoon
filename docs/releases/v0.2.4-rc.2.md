## 本次更新

- 项目与应用全套标识正式更名为 **Lagoon**（应用显示名由 OpenCode Lagoon 变更为 Lagoon）。
- 确立面向多种 coding agent harness 的通用移动控制端定位（首发深度适配 OpenCode 2.x）。
- 样式与主题全面对齐为 `Theme.Lagoon` 与 `LagoonMiuixTheme`（保留兼容别名）。
- 深链接正式启用 `lagoon://` 路由协议（同时保持对历史 `opencode-lagoon://` 路由的兼容支持）。
- 安全存储迁移至 `lagoon-*` 别名，并内置旧别名透明回退机制，确保凭据完整无损。
- CI/CD 发版工作流与产物包命名更新为 `Lagoon-<version>.apk`，兼容读取 `LAGOON_*` 配置。
- `applicationId` 保持为 `com.igng.opencode.lagoon`，签名与证书连续，支持从历史版本平滑覆盖升级。
