## 本次更新

- **后台任务不再误判为已完成**：OpenCode 2.x 的 `/api/session/active` 只覆盖前台运行；把阻塞工具/子代理转入后台（Ctrl+B）后，会话的根执行会进入空闲但并未真正结束，后台任务跑完会自动唤醒 AI。客户端现在只在收到终止事件、或服务端 `time.idle` 越过本轮基线时才收尾，并在后台工作期间显示「后台运行中」，待后台完成重新唤醒 AI 后再恢复正常状态与完成通知。
- **消除「待回复 ↔ 运行中」抖动与误通知**：权限/表单进入等待态后延迟 1.5 秒再发通知，窗口内被处理则不发；请求被回复后撤下对应通知；读取期间到达的等待事件不会被更早的对账结果清除，避免事件与对读竞态造成的假切换。
- **显示调用失败报错**：会话步骤/执行失败时，即使目标消息尚未加载也会触发对账并渲染红色错误行；工具分组在折叠态直接显示首条错误摘要并标红，对齐 OpenCode 客户端的报错呈现。
- 补齐 `session.error`、`session.status`、`session.idle` 等 V2 事件的状态归约。

## 已知限制

- 尚未在真机上对 `session.background`（Ctrl+B）后台任务做端到端验收：需要一台连接真实 OpenCode 2.x 服务器的设备，验证「后台运行中 → 后台完成自动唤醒 AI → 正常完成」的完整链路。
- 「后台运行中」标记依赖服务端写入的合成消息文案（“The backgrounded work is still unfinished…”）；上游若更改文案，需同步更新客户端常量。
- 旧版本持久化的运行态任务缺少本轮时间基线，升级后对账不会据此收尾，会等待终止事件或首次前台读取；个别残留运行态可能短暂保留。
- 从历史 debug 签名版本升级时，旧包可能无法直接覆盖安装稳定签名版本；请按 `docs/ANDROID_SIGNING.md` 处理迁移。
