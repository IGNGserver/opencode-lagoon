## 本次更新

- **运行中的会话只显示过程报告，调用与思考保持折叠**：任务进行中不再把所有工具调用和思考展开，只内联展示过程报告；连续的工具调用按批次折叠成一行小字「调用了 N 次工具」，点击可展开明细。两段过程报告之间的所有调用会合并为一组，运行结束后整轮仍折叠为「共处理 N 个操作 + 最终回复」。
